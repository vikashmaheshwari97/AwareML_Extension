AwareML CI Test Hotfix
======================

ROOT CAUSE
----------
The CI workflow validation itself already passed.

The failing pytest assertion was too brittle:
it searched the Python dict string for this exact quote layout:

river.__version__ == '0.10.1'

After YAML parsing and Python string conversion, quote representation may differ,
so the test can fail even when the workflow is correct.

FIX
---
Only tests/test_ci_runtime_lock.py is changed.

The revised test:
- reads actual `run:` commands from workflow steps;
- verifies river.__version__ is checked;
- verifies 0.10.1 is present;
- verifies xgboost.__version__ and 2.1.4;
- keeps exact OAML package-pin checks.

No CI workflow, Python version, dependencies, Phase-10 protocol,
models, datasets, or results are changed.
