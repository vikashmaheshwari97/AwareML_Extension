AwareML Protocol V3 Upgrade

This package upgrades the existing AwareML repository at base commit 42230343b595a16ccdcf84be80ef244f94f25c07. It contains the complete V3 implementation and an installer with backups. Existing V2 models, historical results and study files stay in place. A new benchmark and new training are required before the V3 recommender can make research-backed predictions.

1 Install in Windows PyCharm

Extract the ZIP into your existing repository root, alongside app.py. Open the PyCharm PowerShell terminal in that directory. Use the existing main Python 3.8 environment. If its directory differs, replace the interpreter path below.

.\.venv\Scripts\python.exe .\APPLY_AWAREML_PROTOCOL_V3.py --check
.\.venv\Scripts\python.exe .\APPLY_AWAREML_PROTOCOL_V3.py
.\.venv\Scripts\python.exe -m pip install -r requirements-protocol-v3.in
.\.venv\Scripts\python.exe scripts/verify_stream_protocol_v3.py
.\.venv\Scripts\python.exe -m pytest tests/test_protocol_v3.py -q
.\.venv\Scripts\python.exe -m streamlit run app.py

Select Meta-Recommender V3 in the app. “V3 training is pending” is the expected state until the new campaign has been collected and the new model bundle copied back. The old Copilot and V2 recommendation workspace continue to use V2. A standalone V3 page is available with python -m streamlit run meta_recommender_v3_app.py.

The installer checks all changes before writing. A conflict means your local version differs from the audited base; the installer stops without installing files. Preserve those edits and merge only the named files from protocol_v3_payload. Do not force overwrite. Repeating a successful install makes no changes. Rollback refuses to replace subsequent edits:

.\.venv\Scripts\python.exe .\APPLY_AWAREML_PROTOCOL_V3.py --rollback-latest

For a fresh checkout, install the existing base requirements and the existing isolated environments first: .\setup.ps1, .\setup_evo.ps1, .\setup_oaml.ps1. Keep their incompatible River versions separate. The upgrade adds FLAML 2.3.4, Vowpal Wabbit 9.10.0, CodeCarbon 3.0.7, psutil 6.1.1, matplotlib 3.7.5, pytest 8.3.5 and setuptools 75.3.2 in the main environment. If the VW wheel is unavailable on Windows, perform the five-adapter integration check on Rocket Linux; primary training does not require ChaCha success.

2 Commit the installed source

Review the source diff and commit only the implementation files. The ZIP is an overlay, so the payload is installed before these Git commands. Your existing repository supplies datasets, framework code and dependencies; this is not a second full copy of the dataset repository.

git switch -c upgrade/stream-protocol-v3
git add awareml/protocol_v3 awareml/ui_v2/meta_recommender_v3.py awareml/ui_v2/pages.py awareml/frameworks/base.py awareml/frameworks/autoclass.py awareml/frameworks/autostreamml.py awareml/workers/evo_worker.py awareml/workers/oaml_worker.py awareml/recommender/service.py configs/stream_protocol_v3.json scripts/awareml_v3.py scripts/verify_stream_protocol_v3.py hpc/protocol_v3 meta_recommender_v3_app.py requirements-protocol-v3.in tests/test_protocol_v3.py docs/stream_protocol_v3
git diff --cached --stat
git commit -m "Add reproducible streaming protocol and meta-recommender V3"
git push -u origin upgrade/stream-protocol-v3

Do not commit installer backups, generated caches, campaign streams or raw result folders accidentally. Archive the frozen campaigns separately. The package includes an original-base patch for inspection; the installer is the recommended application route.

3 Prepare Rocket and test the adapters

Pull the branch on Rocket. The commands below use the existing Conda environment names from the repository’s production launcher. Change these three paths if your actual environments have different names. They are exported for Slurm to inherit. Run smoke tests inside a compute allocation rather than on a shared login node.

git fetch origin
git switch upgrade/stream-protocol-v3
git pull --ff-only
export AWAREML_MAIN_PY="$HOME/.conda/envs/awareml-main/bin/python"
export AWAREML_OAML_PYTHON="$HOME/.conda/envs/awareml-oaml/bin/python"
export AWAREML_EVO_PYTHON="$HOME/.conda/envs/awareml-evo/bin/python"
export AWAREML_OAML_MODE=online
"$AWAREML_MAIN_PY" -m pip install -r requirements-protocol-v3.in
"$AWAREML_MAIN_PY" scripts/verify_stream_protocol_v3.py
srun --exclusive --nodes=1 --ntasks=1 --cpus-per-task=2 --time=00:20:00 "$AWAREML_MAIN_PY" scripts/awareml_v3.py smoke --output artifacts/v3_smoke_rocket --frameworks AutoStreamML AutoClass EvoAutoML OAML ChaCha

Smoke tests use 160 rows on each of two generated streams, one seed and no energy tracking. They are explicitly ineligible for research training. Each output directory must be new. The V3 tests also use generated fixtures solely to check software behavior.

4 Freeze the benchmark protocol

Review configs/stream_protocol_v3.json before preparing: common cap 100000, five seeds 42–46, scientific time limit null, external watchdog 7200 seconds, prefix and window size 1000, two CPU threads and machine-mode CodeCarbon. Verify country_iso for the physical measurement location; EST is the supplied value. Set max_samples to JSON null before preparing if the agreed protocol is full streams. Pilot the common cap, record the decision, then freeze it once for both development and evaluation. Changes after preparation require a new campaign.

"$AWAREML_MAIN_PY" scripts/awareml_v3.py audit-existing --output artifacts/legacy_protocol_audit
"$AWAREML_MAIN_PY" scripts/awareml_v3.py prepare --cohort dev --campaign artifacts/stream_v3_dev
"$AWAREML_MAIN_PY" scripts/awareml_v3.py status --campaign artifacts/stream_v3_dev
"$AWAREML_MAIN_PY" scripts/awareml_v3.py submit --campaign artifacts/stream_v3_dev --concurrency 4 --dry-run
"$AWAREML_MAIN_PY" scripts/awareml_v3.py submit --campaign artifacts/stream_v3_dev --concurrency 4

Add --partition YOUR_PARTITION and --constraint YOUR_CPU_CONSTRAINT to both submit commands as required by Rocket. No partition or node names are invented. Select homogeneous CPU nodes. Concurrent tasks must use different exclusive physical nodes: one measured framework run per node. A node-wide lock also prevents two V3 runs on the same node. If the cluster does not expose exclusive allocation as OverSubscribe=NO or Shared=0, isolation validation stops; inspect the allocation with the cluster administrator rather than asserting dedicated-host mode inside a shared job.

A dedicated workstation can run run --campaign artifacts/stream_v3_dev --serial --resume --dedicated-host. This flag is a declaration that the entire host is reserved for one measured workload. Do not run concurrent tasks, training, smoke tests or other workloads on that measurement host. Isolated CPU cores alone are insufficient for this machine-mode implementation.

47 × 5 frameworks × 5 seeds = 1175 development tasks. Four classification adapters form the primary portfolio; all five, including ChaCha-OVR, form the supplementary extended portfolio. A run executes exactly min(source length, cap) observations in source order. Failure or watchdog expiry is recorded; partial accuracy, projected runtime and imputed energy are never admitted to model training.

5 Prepare the external datasets and run them

The 31 CSVs are not included in the inspected repository. Place their exact expected filenames under data/Testing Datasets/, following configs/phase18_dataset_inventory_31.csv. Default preparation selects 15 native classification datasets; the other 16 were regression-to-classification tasks. To reproduce the entire 31-dataset inventory with leakage-controlled class definitions, explicitly use the supplementary command below. Thresholds then come only from the first 1000 labeled target values. The original regression target and declared sensitive attribute are removed from model inputs.

# Primary native classification cohort: 15 × 5 × 5 = 375 tasks
"$AWAREML_MAIN_PY" scripts/awareml_v3.py prepare --cohort eval --campaign artifacts/stream_v3_eval_native
"$AWAREML_MAIN_PY" scripts/awareml_v3.py submit --campaign artifacts/stream_v3_eval_native --concurrency 4 --dry-run
"$AWAREML_MAIN_PY" scripts/awareml_v3.py submit --campaign artifacts/stream_v3_eval_native --concurrency 4

# Optional whole inventory: 31 × 5 × 5 = 775 tasks
# This is an alternative campaign; native datasets are included again.
"$AWAREML_MAIN_PY" scripts/awareml_v3.py prepare --cohort eval --include-derived --campaign artifacts/stream_v3_eval_31
"$AWAREML_MAIN_PY" scripts/awareml_v3.py submit --campaign artifacts/stream_v3_eval_31 --concurrency 4

The external cohort was already evaluated during earlier work. The new outputs label it a revised external evaluation; it is not a new untouched test set. Freeze model choices on development data before examining these new results. Source hashes and dataset IDs are checked for overlap.

6 Collect without hiding failures

"$AWAREML_MAIN_PY" scripts/awareml_v3.py collect --campaign artifacts/stream_v3_dev --portfolio primary --output artifacts/v3_dev_primary
"$AWAREML_MAIN_PY" scripts/awareml_v3.py collect --campaign artifacts/stream_v3_eval_native --portfolio primary --output artifacts/v3_eval_primary
"$AWAREML_MAIN_PY" scripts/awareml_v3.py collect --campaign artifacts/stream_v3_dev --portfolio extended --output artifacts/v3_dev_extended
"$AWAREML_MAIN_PY" scripts/awareml_v3.py collect --campaign artifacts/stream_v3_eval_native --portfolio extended --output artifacts/v3_eval_extended

Inspect task_status.csv, all_attempts.csv and collection.json. Primary completeness requires all five seeds for all four primary adapters on every included dataset. ChaCha failures do not block the four-adapter portfolio. Extended completeness requires all five adapters. Mixed CPU models or thread allocations block research model training. Memory is the sampled peak sum of worker and child-process RSS over the full worker lifetime, including input data and imports; it is not model-only RAM.

A normal --resume skips every task with an existing attempt, including failures. An intentional retry preserves a separate attempt:

"$AWAREML_MAIN_PY" scripts/awareml_v3.py run --campaign artifacts/stream_v3_dev --task-id 17 --retry

Run retries in an exclusive allocation. Collections use the first attempt by default. A new collection with --latest-attempt explicitly switches that policy and must be reported as a separate analysis. If failures remain, training stops. --complete-case is an explicit sensitivity analysis that excludes incomplete datasets jointly across the portfolio; report all excluded datasets and failure rates. A completed-run status alone does not establish valid energy measurement; check the eligibility column.

7 Train the new recommender and metadata ablation

Train on development-only collections. Nested LODO selects model families inside every outer training fold and refits preprocessing inside every fit. Candidate families are frozen in the config. This is substantially more expensive than ordinary LODO. Run it in a sufficiently long compute allocation, never on the shared login node. The example requests 48 hours; adapt to the cluster’s permitted limit and observed training time. Training itself is not part of the framework energy benchmark.

srun --nodes=1 --ntasks=1 --cpus-per-task=2 --time=2-00:00:00 "$AWAREML_MAIN_PY" scripts/awareml_v3.py train --collection artifacts/v3_dev_primary --output artifacts/recommender_v3 --portfolio primary --features both

Outputs are artifacts/recommender_v3/primary_prefix and primary_metadata. The deployable prefix bundle excludes drift type, dataset family and source type. The metadata bundle includes exactly those three for the requested ablation. It uses the actual registry strings; they are not inferred from the deployment stream. The original V2 model is untouched. Memory is an additional benchmark metric; the four learned objectives remain accuracy, runtime, energy and CO2.

The training parent contains nested_fit_cache. Cache keys include input content, code hash, packages, family and seed. If interrupted, keep the cache and use a new output parent directory with --cache artifacts/recommender_v3/nested_fit_cache. Completed inner fits are reused only when content, code and package hashes match. For a completed prefix bundle and interrupted metadata bundle, train metadata alone into a new parent using --features metadata and the same --cache path. Existing model directories are never overwritten. Cache files and joblib bundles are trusted local Python artifacts; load only your own outputs.

8 Evaluate baselines and compare features

"$AWAREML_MAIN_PY" scripts/awareml_v3.py evaluate --bundle artifacts/recommender_v3/primary_prefix --output artifacts/recommender_v3/primary_prefix_development_evaluation
"$AWAREML_MAIN_PY" scripts/awareml_v3.py evaluate --bundle artifacts/recommender_v3/primary_metadata --output artifacts/recommender_v3/primary_metadata_development_evaluation
"$AWAREML_MAIN_PY" scripts/awareml_v3.py evaluate --bundle artifacts/recommender_v3/primary_prefix --collection artifacts/v3_eval_primary --output artifacts/v3_eval_prefix
"$AWAREML_MAIN_PY" scripts/awareml_v3.py evaluate --bundle artifacts/recommender_v3/primary_metadata --collection artifacts/v3_eval_primary --output artifacts/v3_eval_metadata
"$AWAREML_MAIN_PY" scripts/awareml_v3.py ablation --prefix artifacts/v3_eval_prefix --metadata artifacts/v3_eval_metadata --output artifacts/v3_feature_ablation.csv

For all 31 datasets, collect stream_v3_eval_31 instead and give that collection to the same evaluation commands. Reports include a combined analysis and separate native_classification and derived_classification subdirectories. Never replace the native-only headline with the mixed cohort silently. Compare the prefix and metadata models on the same frozen portfolio, outcomes and preference bank; the ablation command checks this.

Baselines are Single Best Framework, Virtual Best/Oracle, Framework Mean, empirical normalized-utility Prior, the original demo XGBoost architecture refit on V3 inputs, and exact expected uniform Random. The old fitted demo model is incompatible with the revised feature schema and is not reused. Single Best is one fixed framework learned from development mean utility across the frozen preference distribution. Nested-development baseline fits exclude the outer dataset.

Evaluation exports exact and tie-aware Top-1, Top-3, normalized regret, Spearman, dataset bootstrap intervals, closed gap, objective MAE/RMSE and external interval coverage. Four predeclared development profiles give 188 cases if all 47 datasets complete. External evaluation uses 100 frozen profiles per dataset: 1500 native cases or 3100 mixed-inventory cases. Statistical inference uses datasets, so N is 15 or 31, not 1500 or 3100.

Closed gap = (mean selected utility − mean Single Best utility) / (mean Oracle utility − mean Single Best utility). Undefined denominators are null and negative values remain negative. Friedman and Nemenyi compare framework seed means across datasets; SVG critical-difference plots and pairwise tables are produced for accuracy, macro F1, runtime, energy, CO2 and memory. Wilcoxon tests compare dataset-mean recommender outcomes against baselines, with Holm correction within each reported metric family.

For the five-framework supplementary comparison, repeat training/evaluation with the extended collections and --portfolio extended, using a new model parent such as artifacts/recommender_v3_extended. Its manifest and results remain separate from the primary four-framework analysis.

9 Bring the trained model back to PyCharm

Transfer the entire primary_prefix directory, including manifest.json, all eight model files, the development CSV and all manifest-listed files, to artifacts/recommender_v3/primary_prefix in Windows. Use the same main package versions as training. Transfer primary_prefix_development_evaluation beside it if you want baseline evidence in the V3 page. A V2 model.joblib cannot be renamed into V3.

.\.venv\Scripts\python.exe scripts/awareml_v3.py status --bundle artifacts/recommender_v3/primary_prefix
.\.venv\Scripts\python.exe -m streamlit run app.py

# Optional direct prediction using only the labeled prefix
.\.venv\Scripts\python.exe scripts/awareml_v3.py recommend --bundle artifacts/recommender_v3/primary_prefix --csv "data/your_stream.csv" --target target --weights 1 1 1 1 --output artifacts/v3_prediction.json

What can be claimed now

Implemented and software-tested: reproducible preparation, strict adapters, watchdog failures, memory sampling, isolated scheduling, collection, nested training, all baselines, statistical exports, metadata ablation, prediction service, UI and reversible installation. Small synthetic smoke tests are not research results. No new V3 Top-1 accuracy, energy improvement or benchmark ranking has been measured. The historical 91% figure cannot be transferred to V3.

The framework implementations remain the existing AwareML ports and isolated backends. This upgrade aligns the protocol with the supervisor’s requested design; it does not substitute SAMLB’s C++ implementations or establish implementation equivalence with the original papers. ChaCha-OVR is labeled as an AwareML adaptation and reported separately.
