# Main Study Consent Record

Before starting, the participant must actively confirm each statement:

1. **Age/eligibility:** I confirm that I am at least 18 years old.
2. **Participation:** I have read the participant information and voluntarily consent to participate.
3. **Data processing:** I consent to the processing of my study responses as described in the participant information.
4. **Track separation:** I confirm that I did not help author the scenario/stimulus bank used to create these study explanations.
5. **Voluntary withdrawal:** I understand that I may stop participation without penalty and may request withdrawal of linkable pseudonymous data before irreversible anonymization/aggregation.

The application records consent state, participant code hash, protocol/material version and timestamp in the append-only study store.
