AwareML — CI / Reproducibility Hotfix

PURPOSE
-------
Fix the GitHub Actions failures after the Phase-9.6 re-freeze.

The previous CI had these reproducibility problems:
1. GitHub Actions used Python 3.9 even though AwareML is frozen on CPython 3.8.10.
2. The frozen Phase-6 runtime model requires XGBoost 2.1.4, but main requirements did not install it.
3. An old Phase-3 ChaCha test still called the removed pre-OVR private API.
4. The OAML job used Python 3.9, causing River 0.8.0 to build from source instead of using its CPython-3.8 wheel.
