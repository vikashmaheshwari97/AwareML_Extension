AwareML CI Exact CPython 3.8.10 Container Hotfix
=================================================

WHY THIS HOTFIX EXISTS
----------------------
The GitHub Actions log for commit de8eb4e showed:

Version 3.8.10 was not found in the local cache
The version '3.8.10' with architecture 'x64' was not found for Ubuntu 22.04.

This means the failure occurred inside actions/setup-python before dependencies
or tests were executed.

We DO NOT change the project interpreter.

The project remains:
CPython 3.8.10

FIX
---
Both CI jobs now run inside the Docker Official Python image:

python:3.8.10-buster

This image contains CPython 3.8.10 directly, so the workflow no longer depends
on GitHub's setup-python version manifest.

The workflow still uses ubuntu-22.04 as the GitHub host runner, but the actual
test processes execute inside the exact Python 3.8.10 container.

No Phase-10 protocol artifacts, models, datasets, results, Copilot code,
